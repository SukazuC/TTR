# Taskbar Thumbnail Reorder v0.1.1

v0.1.1 adds signed compatibility-data updates without introducing an EXE self-updater, installer,
service, telemetry, or accounts.

- Adds qualified exact record `2620013102` for Windows 11 25H2 build 26200.8875 while retaining the
  prior qualified record.
- Configures the public signed compatibility feed at `SukazuC/TTR-compat`.
- Checks once automatically when an exact taskbar identity is unsupported; manual checking remains
  available.
- Installs only a correctly signed manifest whose sequence exceeds the embedded, current external,
  backup, and highest-installed floors.
- Verifies final files, saves the anti-rollback sequence, restores the prior pair on failure, reloads
  immediately, and retries compatibility without restarting TTR.
- Distinguishes no update, invalid signature, unavailable network, missing endpoint, installed but
  unsupported, and installed-and-activated outcomes.

Release assets are `TaskbarThumbnailReorder.exe` and `SHA256SUMS.txt`.
